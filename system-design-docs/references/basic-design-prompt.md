# 基本設計書 作成プロンプト

## 概要

基本設計書は以下の4つの成果物で構成される。

---

## ① 機能一覧（Excel形式）

システムに実装する機能を一覧にしたもの。

### 構成

| 列           | 内容                         |
| ------------ | ---------------------------- |
| No.          | 連番                         |
| 機能カテゴリ | 大分類（認証、管理、閲覧等） |
| 機能名       | 具体的な機能名               |
| 概要         | 機能の説明                   |
| 対応画面     | 関連する画面ID               |
| 優先度       | 高/中/低                     |
| 備考         | 補足事項                     |

### 出力形式

- Excel (.xlsx)
- ヘッダにPJ名、システム名、作成日、版数を配置

---

## ② 画面設計図（Word形式）

システムにおいてどのような画面を表示するのか設計したもの。要件定義である程度イメージされているものを、より明確に定義する。

### 構成

#### 2.1 画面一覧

| No. | 画面ID | 画面名 | パス | 概要 | ユーザー種別 |
| --- | ------ | ------ | ---- | ---- | ------------ |

#### 2.2 画面遷移図

- 全画面間の遷移関係を図で表現
- 正常時の遷移パターン
- エラー時の遷移パターン
- 認証状態による分岐

#### 2.3 画面レイアウト（画面ごと）

- 各画面のワイヤーフレーム的なレイアウト
- 配置する要素（ヘッダ、フッタ、サイドバー、メインコンテンツ）
- 入力フォームの配置
- ボタン・リンクの配置
- テーブル・リストの配置

#### 2.4 エラー時のパターン

- バリデーションエラー表示
- 認証エラー（未ログイン、権限不足）
- システムエラー（500エラー等）
- データ未存在（404）
- タイムアウト

### 出力形式

- Word (.docx)
- ※写真・スクリーンショットの挿入箇所には「ここに写真を追加」と記載

---

## ③ データベース設計図（Excel + draw.io）

### 3.1 ER図（draw.io形式）

- `drawio-mcp` を使用して作成
- 全テーブル間のリレーションを可視化
- PK/FK の関係を明示
- カーディナリティ（1:1, 1:N, N:M）を記載

### 3.2 テーブル定義書（Excel形式）

各テーブルについて以下を記載：

| 列               | 内容            |
| ---------------- | --------------- |
| No.              | 連番            |
| カラム名（論理） | 日本語名        |
| カラム名（物理） | 英語名          |
| 型               | データ型        |
| 桁数             | 文字数/数値桁数 |
| PK               | 主キーフラグ    |
| FK               | 外部キー参照先  |
| NOT NULL         | 必須フラグ      |
| DEFAULT          | デフォルト値    |
| 説明             | カラムの説明    |

### 3.3 CRUD図（Excel形式）

機能×テーブルのマトリクス表。

| 機能名 | テーブルA | テーブルB | テーブルC |
| ------ | --------- | --------- | --------- |
| 機能1  | CR        | R         | -         |
| 機能2  | R         | CRU       | C         |

C=Create, R=Read, U=Update, D=Delete

### 出力形式

- ER図: draw.io（drawio-mcp使用）
- テーブル定義書: Excel (.xlsx)
- CRUD図: Excel (.xlsx)（テーブル定義書と同一ファイルの別シートでも可）

---

## ④ 外部インターフェース設計図

### 4.1 外部インターフェース一覧

| No. | IF-ID | 連携先システム名 | 連携方式 | データ方向 | 頻度 | 概要 |
| --- | ----- | ---------------- | -------- | ---------- | ---- | ---- |

### 4.2 外部インターフェース定義書（IF別）

| 項目               | 内容                       |
| ------------------ | -------------------------- |
| IF-ID              | インターフェースID         |
| 連携先             | 連携先システム名           |
| 連携方式           | API/ファイル/DB等          |
| プロトコル         | HTTP/SFTP等                |
| データフォーマット | JSON/CSV/XML等             |
| 認証方式           | APIキー/OAuth/なし         |
| エンドポイント     | URL/パス                   |
| リクエスト仕様     | ヘッダ・ボディの定義       |
| レスポンス仕様     | 正常時・異常時のレスポンス |
| エラーハンドリング | リトライ方針等             |

### 4.3 外部インターフェース処理概要

- 連携の手順（シーケンス）
- 前提条件・事前チェック
- 正常時の処理フロー
- 異常時の処理フロー
- 後処理（ログ出力、通知等）

### 出力形式

- Word (.docx) または Excel (.xlsx)

---

## 作成手順

1. プロジェクトの要件定義書・コードベースを読み込む
2. 機能一覧をExcelで作成
3. 画面設計図をWordで作成
4. ER図をdraw.ioで、テーブル定義書・CRUD図をExcelで作成
5. 外部IF設計図を作成
6. 全体の整合性を確認
