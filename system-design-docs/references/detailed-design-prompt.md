# 詳細設計書 作成プロンプト

## 概要

詳細設計書はdraw.io（drawio-mcp）を使用して、以下の4種類のUML図を作成する。

---

## ① クラス図

### 目的

システムを構成するクラス（コンポーネント）間の静的な関係を可視化する。

### 記載内容

- クラス名
- 属性（プロパティ）
- メソッド（操作）
- クラス間の関係
  - 継承（Generalization）
  - 実装（Realization）
  - 関連（Association）
  - 集約（Aggregation）
  - コンポジション（Composition）
  - 依存（Dependency）
- 多重度（1, 0..1, 0.._, 1.._ 等）
- アクセス修飾子（+public, -private, #protected）

### レイヤー構成の例

```
[Pages/Components] → [Server Actions/API Routes] → [Services/Utils] → [Database/Supabase]
```

### 出力形式

- draw.io（drawio-mcp使用）

---

## ② アクティビティ図

### 目的

業務プロセスやシステム処理のフローを可視化する。

### 記載内容

- 開始ノード・終了ノード
- アクション（処理ステップ）
- 判断分岐（ダイヤモンド形状）
- 並行処理（フォーク・ジョイン）
- スイムレーン（アクター/システム/外部サービス別）

### 作成対象の例

- ログイン〜ダッシュボード表示までのフロー
- タスクテンプレート作成→割り当て→進捗入力の業務フロー
- ユーザー招待フロー
- データの検索・登録・更新・削除の各処理フロー

### 出力形式

- draw.io（drawio-mcp使用）

---

## ③ シーケンス図

### 目的

オブジェクト間のメッセージのやり取りを時系列で表現する。

### 記載内容

- ライフライン（アクター、フロントエンド、バックエンド、DB、外部API等）
- メッセージ（同期呼び出し、非同期呼び出し、レスポンス）
- フラグメント
  - alt（条件分岐）
  - loop（ループ）
  - opt（オプション）
  - par（並行処理）
- 活性区間（アクティベーション）

### 作成対象の例

- ログイン処理シーケンス
- テンプレート割り当て処理（トランザクション含む）
- 進捗入力処理
- ダッシュボード表示（集計クエリ含む）
- ユーザー招待〜アカウント有効化

### 出力形式

- draw.io（drawio-mcp使用）

---

## ④ モジュール構成図

### 目的

システムのモジュール（パッケージ・ディレクトリ）構成を可視化する。

### 記載内容

- ディレクトリ/パッケージの階層構造
- モジュール間の依存関係
- 各モジュールの責務の概要

### 構成の例（Next.js App Router）

```
app/
├── (auth)/           # 認証関連ページ
│   ├── login/
│   ├── reset-password/
│   └── set-password/
├── admin/            # 管理者ページ
│   ├── users/
│   ├── templates/
│   ├── assignments/
│   └── tasks/
├── dashboard/        # 新卒ユーザーページ
│   └── tasks/
├── api/              # API Routes
components/           # 共通コンポーネント
lib/                  # ユーティリティ・DB接続
types/                # 型定義
```

### 出力形式

- draw.io（drawio-mcp使用）

---

## 作成手順

1. プロジェクトのコードベース・要件定義書を分析
2. クラス図を作成（主要コンポーネントの関係を定義）
3. 主要な業務フローのアクティビティ図を作成
4. 主要な処理のシーケンス図を作成
5. モジュール構成図を作成
6. 全図の整合性を確認

### drawio-mcp の使用方法

- `drawio-mcp` のツールを使用して各図を生成
- 必要に応じてスタイル・レイアウトを調整
